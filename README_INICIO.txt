SISTEMA JURÍDICO LUCAS TAVARES - PRIMEIRA BASE

1. Extraia a pasta para um local que NÃO esteja dentro do OneDrive.
   Exemplo:
   C:\Projetos\SistemaJuridicoLucas

2. Abra a pasta no VS Code.

3. Abra o terminal do VS Code e execute:

   python -m venv venv

4. Ative o ambiente virtual:

   venv\Scripts\activate

5. Instale as dependências:

   pip install -r requirements.txt

6. Inicie o sistema:

   python app.py

7. Abra no navegador:

   http://127.0.0.1:5000
